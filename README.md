
# BinaryImageConverter

A C# Windows application that converts any file into binary images (using a color palette ranging from 16 to 16.77 million colors), splits and saves them, and allows the original file to be accurately decoded from them.

It offers full pixel and binary compatibility with the Web version running on TypeScript/Canvas.

# Key Features

・**Encode**: Converts any file into multiple binary images.
・**Decode**: Restores the converted binary images to the original file.
・**Specify Image Size**: Exactly what it sounds like.

1. Download the latest `BinaryImageConverter.zip` from the releases page.
2. Extract the zip file and run `BinaryImageConverter.exe`.

**System Requirements**: Windows 10 / 11 (.NET 10.0 runtime)
