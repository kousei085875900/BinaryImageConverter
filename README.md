# BinaryImageConverte
任意のファイルを16~1677万色で構成されたバイナリ画像に変換して分割・保存しそこから、元ファイルを正確にでコードできるc#製のwindowsアプリケーションです。

TypeScript/Canvasで動作するWeb版との完全なピクセル・バイナリ互換性を備えています。

# 主な機能

・**エンコード**: 任意ファイルを複数のバイナリ画像に変換します
・**デコード**  :変換したバイナリ画像を元のファイルに復元します
・**画像サイズの指定**:これは文字通りですね

1.(../../releases) ページから最新の `BinaryImageConverter.zip` をダウンロードします。
2. ジップファイルを解凍し、中にある `BinaryImageConverter.exe` を実行します。
